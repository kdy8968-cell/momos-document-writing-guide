# 업무 문서 작성 가이드

매장과 각 부서에서 업무 절차, 판단 기준, 수행 기록을 공통 Word 양식으로 정리할 때 쓰는 안내입니다. **업무에 맞는 양식 하나를 내려받아** 원자료와 함께 사용하세요.

## 1. 양식 선택

| 양식 | 쓰는 경우 | 작성할 내용 |
| --- | --- | --- |
| [SOP 작업 절차서](templates/SOP.docx?raw=true) | 작업을 일정한 순서로 수행할 때 | 담당자, 준비 사항, 작업 순서, 완료 기준, 이상 시 대응 |
| [GUI 업무 가이드](templates/GUI.docx?raw=true) | 상황에 따라 기준을 확인하고 판단할 때 | 적용 범위, 판단 기준, 예외, 확인할 담당자 |
| [FRM 기록 양식](templates/FRM.docx?raw=true) | 실제 수행한 결과를 남길 때 | 대상, 수행자, 일시, 실제 결과, 후속 조치 |

한 업무에 두 종류 이상이 필요하면 필요한 문서끼리 연결합니다. 예를 들어 SOP에서 점검 순서를 설명하고, FRM에서 실제 점검 결과를 남깁니다.

## 2. 작성 순서

1. 원자료와 선택한 Word 양식을 준비합니다. 양식은 다른 이름으로 저장해 작업 사본을 만듭니다.
2. 적용할 부서·매장과 대상 업무를 명시합니다. 현장에서 쓰는 용어와 실제 수치·단위·조건을 원자료에서 확인해 옮깁니다.
3. AI로 초안을 만들 때는 [작성 프롬프트](writing-prompt.md)를 복사해 원자료 및 빈 양식과 함께 사용합니다. 첨부 전에 원자료의 보안등급과 AI 사용 권한을 확인합니다.
4. 업무 담당자가 초안을 실제 업무와 대조합니다. 승인·시행 및 정본 보관은 해당 부서 절차에 따릅니다.

## 3. 작성 후 확인

- 큰 절에는 번호와 항목명을 붙입니다. 표에는 한 행에 한 기준 또는 한 기록을 넣습니다.
- 영상이나 사진만 봐야 이해되는 동작은 본문에도 적습니다.
- 예외와 중단 조건, 완료를 확인할 사람과 기준을 구체적으로 적습니다. 확인이 필요한 값은 검토 목록에 남깁니다.
- 발행 전에 작성자 안내와 채우지 않은 자리표시자를 정리합니다. 기록 양식은 실제로 한 건 채워보고, 빈 양식과 작성 완료 기록을 구분해 보관합니다.

이 저장소의 Word 파일은 복사해서 채우는 빈 양식입니다. 작성이 끝난 업무 문서는 담당 부서가 정한 위치와 권한으로 관리하세요.
